# Tripleten web_project_homeland

## De Pátria para Pátria

Este projeto consiste no desenvolvimento de uma página web responsiva baseada em um layout do Figma. O objetivo foi criar uma página que apresenta informações sobre as cidades natais de funcionários da TripleTen, reproduzindo o design proposto para diferentes tamanhos de tela.

A página foi construída seguindo os princípios de web design responsivo, garantindo uma boa experiência de visualização em dispositivos desktop, tablet e mobile.

## Funcionalidade

O site exibe um layout adaptável para diferentes resoluções de tela, utilizando uma estrutura semântica e organizada. Entre as principais funcionalidades estão:

- Layout responsivo para desktop, tablet e mobile;
- Adaptação automática do conteúdo por meio de media queries;
- Tipografia utilizando a fonte Inter carregada localmente;
- Conteúdo centralizado com larguras máximas definidas conforme o design;
- Estrutura organizada utilizando a metodologia BEM (Block Element Modifier).

## Tecnologias e técnicas utilizadas

Este projeto foi desenvolvido utilizando:

- HTML5;
- CSS3;
- Metodologia BEM (BEM Flat);
- Flexbox para alinhamento e organização dos elementos;
- Media queries para responsividade;
- Box-sizing: border-box para controle do dimensionamento dos elementos;
- Fontes locais com @font-face;
- Organização modular do CSS em arquivos separados por blocos.
